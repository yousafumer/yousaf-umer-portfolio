# Yousaf Umer | Data Engineer Portfolio

🌐 **Live Portfolio:** https://yousaf-umer-portfolio.vercel.app/

A modern, responsive portfolio built to showcase my experience, projects, technical skills, certifications, and journey as a **Data Engineer** and **Data Analyst**.

The portfolio focuses on clean UI, smooth animations, scalable architecture, and maintainable code. All portfolio content is managed through centralized data files, making it easy to update projects, experience, certifications, and skills without modifying UI components.

# Getting Started

Clone the repository

```bash
git clone https://github.com/yousafumer/yousaf-umer-portfolio
```

Go inside the project

```bash
cd YOUR_REPOSITORY
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
